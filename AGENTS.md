# Instrucciones del proyecto

- Sigue las instrucciones globales de RTK.
- Escribe en español claro y cercano, con tuteo. Conserva una introducción desarrollada y separada de las instrucciones de lectura.
- El orden del manuscrito lo define book.txt. No uses un glob para exportarlo.
- Usa recuadros semánticos .callout .curiosidad y .callout .reto.
- Nunca inventes URLs de recursos, pruebas superadas, reseñas, rankings, ventas ni capítulos terminados.
- El código del libro debe coincidir con el de su repositorio hermano. Comprueba entrada, salida, límites y recursos.
- Actualiza el manifiesto y los estados reales: todo, draft, review, done.
- Solo haz commits locales. No crees remotos, hagas push ni publiques sin una instrucción posterior del usuario.
- Conserva los archivos de C; este proyecto es un volumen independiente.
